# 许可与第三方组件

本项目依赖并分发以下上游组件，须遵守其许可证：

| 组件 | 许可 | 说明 |
|---|---|---|
| QEMU | GPLv2 | 动态翻译引擎；须保留版权声明与许可证 |
| Linux Kernel | GPLv2 | ARM64 `virt` 内核 |
| Debian 12 | 各包上游许可 | 官方用户空间 |
| libslirp / glib（如使用） | GPLv2 / LGPL | 可选依赖 |

要求：

- 保留所需版权声明与许可证文件（见 `LICENSES/`）。
- 记录依赖版本与修改内容（见 `QEMU/VERSIONS.txt`）。
- 提供源码获取方式（上游 URL + 固定提交）。
- 不将第三方组件错误标记为完全自主开发。

分发预构建 Kernel / Debian 镜像时须确认再分发条件；Debian 允许自由再分发。
